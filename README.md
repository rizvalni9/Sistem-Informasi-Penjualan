Proyek ini adalah Sistem Informasi Penjualan untuk mengelola data barang penjualan, membuat transaksi dan menampilkan laporan penjualan dibuat menggunakan bahasa pemorgraman Java JDK versi 17 dan penyimpanan data berbasis SQL.

Sebelum menggunakan atau menjalankan aplikasi ini, pastikan mengimpor database db02_23si11 ke dalam sistem manajemen basis data seperti MySQL.
